# Libreria multimediale {#media-page}

La pagina della libreria consente di gestire i file multimediali dell'applicazione, modificare i brani scaricati e aggiungerne di nuovi.

![Libreria multimediale](../assets/images/media.webp)

## Funzionalità principali {#highlights}

<div class="grid cards" markdown>

-   ![Controllo del palco dalla coda](../assets/images/media/external.gif)

    __Aggiungere file multimediali in diversi modi__

    Aggiungi file multimediali tramite l'applicazione oppure direttamente nella cartella dei media.

    - Carica tracce audio e video tramite l'applicazione.
    - Separa la voce dai file caricati e prepara i brani per il karaoke.
    - Rileva i file e gli altri contenuti multimediali gestiti da applicazioni esterne.
    - Esporta rapidamente i file per il backup o la condivisione.

-   ![Aggiungere un brano alla coda](../assets/images/media/create.gif)

    __Creare karaoke con l'IA dai file esistenti__

    Rimuovi la voce e crea testi sincronizzati per qualsiasi file già presente nella libreria.

    - Non è necessario seguire il processo di download di YouTube.
    - Separa la voce dalle tracce esistenti.
    - Cerca i testi e sincronizzali per il karaoke.
    - Scarica, rinomina o elimina i sidecar del brano.

-   ![Autopilota](../assets/images/media/autopilot.gif)

    __Caricamento automatico__

    Un insieme predefinito di opzioni che configura l'elaborazione karaoke con un solo clic.

    - Ricava automaticamente i dati del brano dal nome del file.
    - Cerca e scarica i testi della traccia.
    - Compila titolo, artista e opzioni di elaborazione karaoke.
    - Applica le impostazioni consigliate per l'elaborazione prima di inviare il brano.

</div>

## Operazioni disponibili {#what-you-can-do}

<div class="grid cards" markdown>

-   :material-filter-variant:{ .lg .middle } __Cercare e filtrare i file multimediali__

    ---

    Cerca brani nell'intera libreria e filtra i risultati in base alla presenza di una traccia vocale o di testi sincronizzati.

-   :material-playlist-plus:{ .lg .middle } __Aggiungere alla coda dalla libreria__

    ---

    Aggiungere brani alla coda di riproduzione mentre si consulta la libreria multimediale.

-   :material-refresh:{ .lg .middle } __Scansionare e aggiornare la libreria__

    ---

    Rileva le modifiche nel filesystem o aggiorna i dati di un singolo brano.

-   :material-rename-box:{ .lg .middle } __Rinominare in modo intelligente__

    ---

    Usa Last.fm per ricavare automaticamente titolo e artista dai titoli dei video YouTube.

-   :material-tune:{ .lg .middle } __Opzioni avanzate__

    ---

    Configura le opzioni di allineamento dei testi con WhisperX per i file esistenti o caricati.

</div>
