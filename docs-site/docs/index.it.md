## Benvenuto {#welcome}

DMKaraoke (Demucs Karaoke App) è un'applicazione web leggera per il karaoke domestico. Utilizza l'apprendimento automatico per separare le tracce vocali e creare testi sincronizzati parola per parola. È **completamente gratuita**, **senza pubblicità** e **senza abbonamenti a servizi cloud**. Crea il karaoke direttamente sul tuo dispositivo.
